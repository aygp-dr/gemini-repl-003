#+AUTHOR: jwalsh

* Overview

A simple, console-based REPL application in ClojureScript that interfaces with Google's Gemini API.

* Features

- Interactive REPL with slash commands (/help, /exit, /clear)
- Conversation context tracking
- Token usage and cost tracking
- Formal specifications using TLA+ and Alloy
- Comprehensive logging system

* Installation

1. Clone the repository
2. Copy =.env.example= to =.env= and add your Gemini API key
3. Run =make install= to install dependencies
4. Run =make build= to build the application
5. Run =make run= to start the REPL

* Usage

Start the REPL with:
#+BEGIN_SRC bash
make run
#+END_SRC

Available commands:
- =/help= - Show available commands
- =/exit= - Exit the REPL
- =/clear= - Clear the screen
- =/stats= - Show token usage statistics
- =/debug= - Toggle debug mode
- =/context= - Show conversation context

* Development

For development with live reload:
#+BEGIN_SRC bash
make dev
#+END_SRC

Run tests:
#+BEGIN_SRC bash
make test
#+END_SRC

Run linter:
#+BEGIN_SRC bash
make lint
#+END_SRC

** bb tasks

This repo follows the aygp-dr Clojure standard: =deps.edn= is the canonical
manifest (=shadow-cljs.edn= uses ={:deps {:aliases [:cljs :dev]}}=) and
=bb.edn= provides the tasks. Run =npm ci --ignore-scripts= once first.

| Task                    | What it does                                           |
|-------------------------+--------------------------------------------------------|
| =bb test=               | =npx shadow-cljs compile test && node target/test.js=  |
| =bb lint=               | clj-kondo (fails on errors)                            |
| =bb fmt= / =bb fmt:fix= | cljfmt check / fix                                     |
| =bb check=              | lint + fmt + test (CI runs this)                       |

=bb test= runs node with a dummy =GEMINI_API_KEY=, so tests never see a real
key and never call the API.

** Specs

Data specs live in =src/gemini_repl/specs.cljs=, and each public fn in
=gemini-repl.core= has an =s/fdef= right after its =defn= (see the
[[https://clojure.org/guides/spec][clojure.spec guide]]).
=test/gemini_repl/specs_test.cljs= runs =stest/check= over =log-entry= and
property-tests the =/debug= state transition and the =/stats= output. The unit
tests run with instrumentation on; at the shadow-cljs REPL, =(require 'user)=
instruments too.
